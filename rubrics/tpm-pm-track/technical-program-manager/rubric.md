# Technical Program Manager Competency Rubric

This rubric defines the role-specific competencies for Technical Program Managers at each level. All TPgMs are also evaluated on the three [Universal Criteria](../../../docs/universal-criteria.md): Craft/Quality, Speed, and Adaptiveness.

---

## Level Overview

| Level | Title | Scope | Key Competencies |
|-------|-------|-------|------------------|
| TPgM1 | Program Manager | Multiple related projects | Program Execution, Cross-Project Coordination, Stakeholder Management, Technical Understanding |
| TPgM2 | Senior Program Manager | Strategic programs | Program Leadership, Strategic Planning, Executive Communication, Organizational Influence |
| TPgM3 | Principal Program Manager | Organization-level programs | Portfolio Strategy, Organizational Transformation, Executive Partnership, Industry Expertise |

---

## TPgM1: Program Manager

### Scope
Managing multiple related projects as a unified program.

### Competencies

#### Program Execution

**Definition**: Executing programs of multiple related projects

**Level 4 - Meets Expectations:**
- Manages multiple projects as a program
- Creates program roadmaps
- Tracks program-level milestones
- Delivers program outcomes
- Coordinates across projects

**Level 3 - Needs Improvement:**
- Treats projects independently
- Poor program-level view
- Inconsistent delivery

**Level 2/1 - Below Expectations:**
- Programs fail to deliver
- Cannot manage at program level

**Development Suggestions:**
- Study program management
- Learn portfolio tools
- Practice dependency mapping
- Review program retrospectives

#### Cross-Project Coordination

**Definition**: Coordinating dependencies across projects

**Level 4 - Meets Expectations:**
- Maps dependencies across projects
- Coordinates teams effectively
- Resolves cross-project conflicts
- Optimizes resource allocation
- Identifies integration risks

**Level 3 - Needs Improvement:**
- Dependencies not well managed
- Poor coordination
- Conflicts escalate

**Level 2/1 - Below Expectations:**
- Dependencies cause failures
- Cannot coordinate

#### Stakeholder Management

**Definition**: Managing program stakeholders and governance

**Level 4 - Meets Expectations:**
- Creates program governance
- Manages executive sponsors
- Reports program status effectively
- Builds stakeholder relationships
- Influences program decisions

**Level 3 - Needs Improvement:**
- Poor stakeholder engagement
- Governance unclear
- Cannot influence

**Level 2/1 - Below Expectations:**
- Stakeholder relationships damaged
- No governance

#### Technical Understanding

**Definition**: Understanding technical aspects of program

**Level 4 - Meets Expectations:**
- Understands technical architecture
- Identifies technical risks
- Partners with technical leads
- Translates technical to business
- Evaluates technical trade-offs

**Level 3 - Needs Improvement:**
- Limited technical understanding
- Cannot evaluate trade-offs

**Level 2/1 - Below Expectations:**
- Technical gaps cause issues

## TPgM2: Senior Program Manager

### Scope
Strategic program management with significant business impact.

### Competencies

#### Program Leadership

**Definition**: Leading strategic programs

**Level 4 - Meets Expectations:**
- Leads critical strategic programs
- Drives program vision
- Makes tough program decisions
- Handles significant ambiguity
- Delivers transformational outcomes

**Level 3 - Needs Improvement:**
- Struggles with strategic scope
- Poor decision making
- Cannot handle ambiguity

**Level 2/1 - Below Expectations:**
- Strategic programs fail
- Cannot lead at this level

#### Strategic Planning

**Definition**: Developing strategic program approaches

**Level 4 - Meets Expectations:**
- Creates strategic program plans
- Aligns programs with company strategy
- Identifies strategic opportunities
- Plans multi-year roadmaps
- Adjusts strategy based on results

**Level 3 - Needs Improvement:**
- Limited strategic alignment
- Poor long-term planning

**Level 2/1 - Below Expectations:**
- No strategic approach

**Development Suggestions:**
- Study strategic planning
- Learn company strategy
- Practice strategic alignment
- Get executive mentorship

#### Executive Communication

**Definition**: Communicating effectively with senior leadership

**Level 4 - Meets Expectations:**
- Communicates to executives effectively
- Influences executive decisions
- Provides appropriate detail
- Delivers difficult messages well
- Builds executive trust

**Level 3 - Needs Improvement:**
- Struggles with executive communication
- Cannot influence decisions

**Level 2/1 - Below Expectations:**
- Poor executive relationships

#### Organizational Influence

**Definition**: Influencing beyond program scope

**Level 4 - Meets Expectations:**
- Influences organization-wide decisions
- Shapes program management practices
- Builds coalitions for change
- Develops future leaders
- Creates organizational capabilities

**Level 3 - Needs Improvement:**
- Influence limited to program
- Doesn't build capabilities

**Level 2/1 - Below Expectations:**
- No organizational influence

---

## TPgM3: Principal Program Manager

### Scope
Organization-level programs and transformation.

### Competencies

#### Portfolio Strategy

**Definition**: Developing program portfolio strategy

**Level 4 - Meets Expectations:**
- Shapes program portfolio strategy
- Prioritizes programs strategically
- Identifies new program opportunities
- Optimizes portfolio value
- Advises on strategic investments

**Level 3 - Needs Improvement:**
- Limited portfolio view
- Poor prioritization

**Level 2/1 - Below Expectations:**
- Cannot think at portfolio level

#### Organizational Transformation

**Definition**: Leading organizational change through programs

**Level 4 - Meets Expectations:**
- Leads organizational transformation
- Drives culture change
- Creates sustainable processes
- Builds organizational capabilities
- Manages change resistance

**Level 3 - Needs Improvement:**
- Transformation scope limited
- Cannot drive change

**Level 2/1 - Below Expectations:**
- Transformation fails

**Development Suggestions:**
- Study change management
- Learn organizational design
- Practice transformation leadership
- Build executive relationships

#### Executive Partnership

**Definition**: Partnering with executives on strategic initiatives

**Level 4 - Meets Expectations:**
- Partners with C-level executives
- Advises on strategic decisions
- Influences company direction
- Builds trusted relationships
- Represents program function at highest level

**Level 3 - Needs Improvement:**
- Limited executive partnership
- Cannot influence at C-level

**Level 2/1 - Below Expectations:**
- Poor executive relationships

#### Industry Expertise

**Definition**: Being recognized program management expert

**Level 4 - Meets Expectations:**
- Recognized PM expert
- Represents company externally
- Publishes program content
- Brings external perspectives
- Builds industry relationships

**Level 3 - Needs Improvement:**
- Expert internally only
- Limited external presence

**Level 2/1 - Below Expectations:**
- Not recognized as expert
